Add a user

A temporary password is created; the person chooses their own at first sign-in. A portal admin manages users and backups and is Admin in every app and every camp. Everyone else only sees the camps you tick, in every app.

Accounts

Roles inside each app

  • No access – the app is not shown to the person.
  • Viewer – can look at everything (in Camp: except Location Profit) but cannot change anything.
  • Operator – Camp: check in/out, reservations, resident details, room sizes, bathrooms, housekeeping. Manpower and Costing: can change data.
  • Admin – everything inside that app (Camp: blocks, rooms, capacity, companies, camps, deleting log records, profit; Costing: clearing a day).
  • Camps – a person only sees the camps ticked for them, in every app: Camp Management shows only those camps' blocks, rooms and records; Manpower, Costing, Duty Board and Dining Halls let them open only those camps' data. Their role in an app is the same in all their camps.
  • Duty Board – an Admin sees and manages all departments. An Operator (department head) or Viewer only sees the departments you tick with the Departments button: Operators edit them, Viewers only look.

Camps

Every app uses this list. Camp Management keeps all camps together (each block belongs to a camp); Manpower, Daily Costing, Duty Board and Dining Halls keep separate data for each camp: a new camp starts empty there (its Admin sets it up, or imports a file in Backups & import). People only see the camps ticked for them on the Users tab.

⬇ Download current data

Every change is saved in the database permanently. In addition, a full copy is kept at the start of each day (last 60 days), before every import, and whenever you click “Back up now”. The server also makes a nightly database dump (see README).

Import data from a desktop program

On the PC with the desktop program, open %APPDATA%\<program name>\ and choose app_data.json (folder global-village-camp-management for Camp, ges-manpower-system for Manpower, ges-daily-costing-stock for Costing, duty-board for Duty Board). For Costing, a backup made with its “Export JSON” button also works.
This replaces all data of the chosen app. The current data is kept as a backup first, and everyone using that app reloads.
